Architecture

Agents produce judgement. Code produces every number.

1 · Evidence
data/*.csv→ Loader→ Payment agent News agent → Evidence Store

The Loader is the leakage boundary — it refuses the label tables and strips the answer columns out of news. Producers never score.

2 · Judgement
Evidence Store→ adjudicate() — the formula→ score · band · PD → Adjudicator review

The only place a number is produced. The review agent agrees, caveats or challenges — and cannot change the score.

3 · Action
Limit recommendations→ Case File agent→ draft for the risk underwriter→ dashboard

Every figure the agent writes is checked against the data before it renders. Fail twice and a template renders instead, and says so.

What we’d build next

None of it needs a new data source.

  • Cross-insurer payment data. One buyer going late to five suppliers at once, not one — the signal only a carrier has.
  • Parent company contagion, past the first hop. Today it runs one level down. Next: up from a subsidiary, across siblings, and aggregated at the group cap.
  • Further signal analysis for the case file. Buyer rating, country cap, multi-year financials, assessment history — already collected, not yet read.
